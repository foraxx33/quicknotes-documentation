# Документация для программы QuickNotes

## Возможности

- **Записывайте** планы, мысли и другую информацию
- Записывайте информацию с помощью **голосового ввода**
- QuickNotes позволяет создавать **календари с напоминаниями**
- **Делитесь** своими планами и разработками с другими пользователями с помощью функции **Share**

## Поддерживаемые платформы

- Компьютеры
  - Windows
  - macOS
- Мобильные устройства
  - Android
  - iOS

## Установка приложения

1. Откройте **App Store** или **Google Play**
2. Наберите в поиске **QuickNotes**
3. Нажмите кнопку **Установить**
4. Введите пароль и нажмите кнопку **Продолжить**

> **Важно:** Для установки QuickNotes требуется подключение к интернету

## Запуск QuickNotes

1. Откройте терминал
2. Перейдите в папку `QuickNotes`
3. Выполните следующие команды

```bash
npm install
npm start 
```

> **Важно:** Не закрывайте терминал во время работы приложения

4. После запуска откройте `localhost:3000` в браузере.

Файл `config.json` содержит настройки приложения.

## Устранение неполадок

Если QuickNotes не запускается:
1. Проверьте подключение к сети Интернет
2. Убедитесь, что установлена последняя версия приложения
3. Перезапустите QuickNotes

## Смена пароля от аккаунта

### Пароль от аккаунта сменяется в трех случаях
- В целях безопасности пароль необходимо изменять каждые 180 дней
- Если пользователь забыл пароль
- При подозрении на утечку конфиденциальных данных

Чтобы изменить пароль, выполните следующие действия:
1. Нажмите на иконку вашего профиля в правом верхнем углу
2. Выберите **Конфиденциальность и пароли**
3. Нажмите на кнопку **Изменить пароль** 
4. Введите старый пароль
5. Введите новый пароль

Чтобы восстановить пароль, выполните следующие действия:
1. Нажмите на иконку вашего профиля в правом верхнем углу
2. Выберите **Конфиденциальность и пароли**
3. Нажмите на кнопку **Изменить пароль**
4. Снизу окна ввода старого пароля нажмите на **Forgot my password**
5. Введите адрес вашей электронной почты 
6. В полученном письме от *QuickNotes.adm* пройдите подтверждение личности
7. Придумайте новый пароль

> **Важно:** Не сообщайте пароль другим пользователям. Для безопасного хранения используйте менеджер паролей.

## Экспорт заметок
Если вы хотите поделиться своими заметками с другими пользователями, у которых нет приложения QuickNotes, вы можете использовать функцию **Export**

Чтобы успешно экспортировать заметки в формате PDF, выполните следующие действия:
1. Наведите курсор мыши на название вашей заметки
2. Во всплывающем окне нажмите на значок **+**
3. Выберите **Export to PDF**
